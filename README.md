# Demonstração — Kalon Beauté

Proposta de página para apresentação ao cliente. **Não é o site oficial** da Kalon Beauté.

O arquivo `index.html` na raiz é o site estático, pronto para publicação na Vercel. O botão de WhatsApp só abre um aviso nesta página; nenhuma mensagem é enviada. O `robots.txt` pede que os buscadores não indexem esta demonstração.
